# Обновление v14 — правила игры

- Светлая и тёмная темы и полный экран доступны в верхней панели. Выход из полного экрана сам по себе не штрафуется.
- Рейтинг открывается справа поверх задания и обновляется примерно каждые 2 секунды при наличии связи. Места определяются по рейтингу, затем по числу решённых задач и времени финиша.
- Внизу добавлена вкладка «Награды»: текущая и лучшая серия, полученные бонусы и предварительные достижения.
- Каждые 3 разных задания, решённых подряд с первой попытки, дают +1 бонус, максимум +5 за игру. Ошибка, передача и завершение без ответа сбрасывают текущую серию. Блиц в серию не входит.
- Задание можно один раз передать сокоманднику. История попыток сохраняется; у получателя новый набор попыток. Получатель решает задание либо нажимает «Нет ответа — завершить за 0». В соло доступно завершение за 0. Ошибочный ответ и отсутствие ответа различаются в интерфейсе и журнале.
- В блице у каждого участника свой вопрос из одной группы типа/категории/сложности. Первые верные ответы дают 3/2/1 балла. Вошедшие после начала раунда участвуют со следующего блица. Преподаватель видит список выданных вопросов.
- Режим внимания включается преподавателем до старта комнаты. Для каждого ухода со страницы первые 10 секунд бесплатны; далее −1 за каждые полные 30 секунд. Максимум −5 за игру; результат не ниже нуля. Списание производится после возвращения и фиксируется на листе «Внимание». Работа зависит от событий браузера и связи с сервером; это не доказательство списывания.
- Python подготавливается при входе студента. Проверка и сохранение показываются отдельно. При проблемах загрузки или бесконечном цикле выводится ошибка с возможностью повторить.
- В Results добавлены лучшая серия, бонус серии, штраф, время вне вкладки и число заданий без ответа. В «Передачи» сохраняется история передачи заданий.
- Серверный файл с ответами остаётся только в Apps Script. Адрес сервера, таблица и пароль преподавателя сохранены.

Ниже — исходная инструкция по настройке и базовым экранам. При отличиях в игровых правилах используйте описание v14 выше.

## 1. Первая настройка

Делается один раз. Сайт уже опубликован на GitHub Pages, нужна только Google Таблица со скриптом.

> 🔒 **Файл скрипта `apps-script.gs` с ключами ответов — закрытый.** Его нет в репозитории, и выкладывать его (или ключи ответов) на GitHub нельзя, иначе студенты увидят ответы. Файл вы получаете отдельно от автора.

1. **Таблица.** Создайте Google Таблицу (или откройте существующую с результатами).
2. **Скрипт.** В таблице: *Расширения → Apps Script*. Удалите всё в редакторе и вставьте **целиком** содержимое `apps-script.gs`. Нажмите 💾 Сохранить.
3. **Пароль (по желанию).** В начале файла: `var TEACHER_PASSWORD = '';`. Впишите пароль в кавычки, если хотите, чтобы комнаты создавал только знающий пароль.
4. **Развёртывание.** *Начать развёртывание → Новое развёртывание → тип «Веб-приложение»*:
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
   - Нажмите «Развернуть», разрешите доступ к таблице. Скопируйте URL (оканчивается на `/exec`).
5. **config.js.** URL должен стоять в файле `config.js` репозитория: `const APPS_SCRIPT_URL = "…/exec";`. Сейчас там уже указан рабочий URL, менять нужно только если вы создали **новое** развёртывание.
6. **Проверка.** Откройте в браузере `ВАШ_URL/exec?a=ping`. Должно быть `{"ok":true,"tasks":881}` (число задач в банке).

### Обновление скрипта (новая версия от автора)

1. Apps Script → замените весь код новым `apps-script.gs` → Сохранить.
2. **Развернуть → Управление развертываниями → ✏️ (карандаш) → Версия: «Новая версия» → Развернуть.**
3. URL остаётся прежним, `config.js` не трогаем. Проверьте `?a=ping`.

⚠️ Не создавайте «Новое развёртывание» для обновления: у него будет **другой** URL, и сайт продолжит ходить в старый.

## 2. Проведение занятия

### Шаг 1. Комната
- Откройте **…/python-quiz/#teacher** (с компьютера/проектора удобнее).
- Введите пароль (если задан) → **«Создать комнату»**.
- На экране крупно — **6-значный код**. Покажите его классу.
- Ключ преподавателя хранится только в этом браузере. Не нажимайте «Выйти из комнаты», пока занятие не закончилось, — вернуться будет нельзя.

### Шаг 2. Студенты входят
Студенты открывают https://aizenkremer.github.io/python-quiz/ на телефоне:
1. ФИО и группа → «Далее».
2. Выбор: **➕ Создать команду**, **👥 Войти в команду** (по коду комнаты или по коду команды вида `ABC123-1`), **🧑‍💻 Играть соло**.
3. В команде максимум **4** человека.

<img src="docs/img/choice-iphone12.png" width="260" alt="Выбор режима">

У вас на экране — список команд и строка «Без команды: …».

### Шаг 3. Выборы капитана
- **«Открыть выборы капитанов»** — 90 секунд, каждый голосует (можно за себя).
- Когда проголосовали все или вышло время — анимация с капитаном. Ничья — случайный выбор.
- Соло-игроки выборы пропускают.
- Можно сразу нажать **«Сразу к задачам»**: капитаны тогда выбираются автоматически.

<img src="docs/img/election-iphone12.png" width="260" alt="Выборы капитана">

### Шаг 4. Решение задач
- **«Начать решение задач»**. Каждая команда получает свой набор (см. [раздел 5](#5-набор-задач-дня)).
- **Капитан** раздаёт задачи участникам. Ему подсказывается, сколько задач с кодом ⌨️ на человека (≈3–4), и видна нагрузка каждого.
- Соло-игроку все задачи назначены сразу.

<img src="docs/img/v13-captain-code-hint-iphone12.png" width="260" alt="Распределение задач капитаном">

### Шаг 5. Во время игры
- **Мониторинг:** у каждой команды — рейтинг %, решено/провалено, баллы участников, чат команды (кнопка «💬 Чат»). Ссылки «помогите» в чате открывают задачу и текущий код студента.
- **⚡ Блиц:** кнопка «⚡ Блиц» — одна быстрая задача всем на 2 минуты, первые верные получают 3 / 2 / 1 бонусных балла. Один ответ на человека.
- **✖ Кикнуть** (у каждого игрока): игрок удаляется из комнаты. Его нерешённые задачи возвращаются капитану нераспределёнными, если он был капитаном — капитаном становится другой участник. Студент увидит «Преподаватель удалил вас из комнаты — можно зайти заново» и может войти снова по коду (как новый участник).
- **Расформировать команду:** участники возвращаются к выбору «Создать / Войти / Соло». Их отправленные ответы остаются в таблице.
- **Опоздавшие:** студент может вступить в команду (если там < 4 человек) и во время игры. Набор задач команды **вырастет** до нормы нового размера (15 → 25 → 38 → 50), новые задачи придут капитану нераспределёнными, в чат команды придёт сообщение.

Перед киком и расформированием всегда спрашивается подтверждение.

<img src="docs/img/teacher-kick-disband-iphone12.png" width="260" alt="Кнопки преподавателя">

### Шаг 6. Завершение
- **«Завершить и записать результаты»** — ответы больше не принимаются, итоги пишутся в листы `Results`, `TeamResults`, `Достижения`.
- **«Записать результаты в таблицу»** можно нажимать и во время игры — промежуточная выгрузка без дублей.
- Студенты видят финальную таблицу мест.

## 3. Что видят студенты

- **Вкладки внизу:** 📋 Задачи · 💬 Чат · 🏆 Команды (рейтинг + 🔔 Лента событий) · 👤 Моё.
- **Вставка запрещена** во всех полях ответа, в редакторе кода и в чате («Вставка отключена — пишите сами 🙂»). Попытки вставки учитываются в таблице.
- **Помощь:** «🆘 Помогите с задачей» можно попросить **только по своей назначенной и ещё открытой** задаче. Свои решённые и проваленные задачи студент видит в разделе «Закрытые», но помощь по ним просить нельзя.
- **Уведомления** — маленькое всплывающее сообщение сверху на ~2,5 с, одно за раз, без звука. Всплывает только:
  - «📌 Вам назначено задач: N»
  - старт блица (с короткой вибрацией)
  - просьба о помощи от товарища
  - кик / расформирование команды

  Всё остальное (чат, чужие решения и финиши, итоги блица) — тихо: счётчик на вкладке и запись в «Ленте». Пока студент печатает ответ, уведомления не показываются.
- **Блиц** не открывается сам: внизу плашка «⚡ Блиц: ответить», окно — по нажатию.
- **Проверка кода** выполняется прямо в телефоне. Она терпима к мелочам (лишние пробелы, регистр, `print` вместо `return`, `5` и `5.0`). При ошибке показывается: какая проверка, что ожидалось и что получено, подсказка (забыли `return`, `int()`, лишний текст). Первые 2 проверки видны, остальные скрытые.
- **Финиш команды:** когда все задачи закрыты — финальный экран с местом и шуточными достижениями (один раз).

## 4. Баллы и рейтинг

| Что | Баллы |
|---|---|
| Задача с кодом ⌨️ | 2 |
| Остальные задачи | 1 |
| Свободный ответ 📝 | 0 автоматически, ДопБаллы 0–3 ставит преподаватель |
| Первым в комнате решил задачу | +1 бонус |
| Блиц: 1-й / 2-й / 3-й+ верный | +3 / +2 / +1 бонус |

**Попытки:** выбор варианта — 1, число/текст/порядок строк — 2, код — без ограничений (засчитывается, когда пройдены все проверки), свободный ответ — 1.

**Рейтинг %** (по нему места):

```
Рейтинг % = баллы ÷ максимум баллов своего набора × 100 + min(15, бонусы ÷ число участников)
```

- Набор задач пропорционален числу людей (~12–13 задач на человека), поэтому соло и команды сравниваются **в процентах**, а не в сырых баллах.
- Бонус считается «на человека» и ограничен +15 п.п.
- Место: сначала финишировавшие (по времени финиша), потом по доле закрытых задач, потом по рейтингу.
- **Баланс соло и команд:** при одинаковой силе базовый процент одинаков (максимум ≈1,2 балла на задачу при любом размере). Команды обычно получают чуть больше бонусов «первым решил» (решают параллельно).

## 5. Набор задач дня

Набор зависит от кода комнаты и даты (каждый день новый). Около 25% — задачи с написанием кода, остальное — программирование без кода.

| Размер | Всего | ⌨️ Код | 🧩 Без кода | 📝 Свободный | Логика | Архитектура | Математика |
|---|---|---|---|---|---|---|---|
| Соло | 15 | 4 | 10 | 1 | 0 | 0 | 0 |
| 2 чел. | 25 | 6 | 16 | 2 | 1 | 0 | 0 |
| 3 чел. | 38 | 10 | 24 | 2 | 1 | 1 | 0 |
| 4 чел. | 50 | 13 | 31 | 3 | 1 | 1 | 1 |

**Типы задач без кода 🧩:** Угадай вывод, Найди строку с ошибкой, Заполни пропуск, Понятия, Собери код (кнопки ↑↓), Сопоставь выражение и значение, Сколько раз выполнится цикл, Значение переменной, Верно или нет, Выбери исправление. Плюс игровые 🎮: Взломай замок, Детектив и др. Ответы — нажатием кнопок или числом, печатать почти не нужно.

## 6. Листы таблицы

Создаются автоматически при первом использовании. Скачать в Excel: *Файл → Скачать → Microsoft Excel (.xlsx)*.

| Лист | Что там |
|---|---|
| **Rooms** | Служебное состояние комнат. Не редактируйте. |
| **Submissions** | Каждая отправка: время, комната, команда, ФИО, группа, задача, тип, верно (1/0), ответ или код, попытки вставки. Блиц тоже здесь. |
| **Results** | Итог по студентам: команда, капитан, решено, баллы, бонус, рейтинг %. |
| **TeamResults** | Итог по командам: участники, решено, баллы, бонус, место финиша, размер набора, максимум баллов, рейтинг %, итоговое место. |
| **РучнаяПроверка** | Свободные ответы: вопрос, ответ студента, пустой столбец **ДопБаллы (0–3)**. |
| **Чат** | Все сообщения командных чатов. |
| **Достижения** | Шуточные достижения команд и соло. |

Удалённые (кикнутые) игроки в `Results` не попадают, но их отправки остаются в `Submissions`.

## 7. Ручная проверка свободных ответов

1. Откройте лист **РучнаяПроверка**.
2. Прочитайте «Вопрос» и «Ответ».
3. Впишите в **ДопБаллы (0–3)**: 0 — нет ответа/списано, 1 — частично, 2 — верно, 3 — отлично и своими словами.
4. ДопБаллы прибавляются к итоговой оценке при выставлении (не выше 100). Студенты в игре видят у таких задач статус «на проверке 📝».

Столбец «Вставки» помогает заметить попытки скопировать текст.

## 8. Вопросы и проблемы

**Результаты не сохраняются / «нет связи».**
- Проверьте `…/exec?a=ping` — должно быть `{"ok":true,…}`.
- Обновите страницу на телефоне (браузер мог закэшировать старый `config.js`). Если не помогло — закройте вкладку и откройте ссылку заново.
- Убедитесь, что доступ развёртывания — **Все**, а не «Только я».

**После обновления скрипта ничего не изменилось.**
- Вы сохранили код, но не сделали *Управление развертываниями → ✏️ → Новая версия*. Без этого работает старая версия.

**Ошибка «Нет доступа преподавателя».**
- Ключ комнаты хранится в браузере, где её создали. Откройте `#teacher` в том же браузере или создайте новую комнату.

**Ошибка при развёртывании / «Требуется авторизация».**
- Запустите любую функцию в редакторе один раз и подтвердите доступ к таблице. Выполнять как — **Я**.

**Студент «потерялся» (закрыл вкладку, сел телефон).**
- Пусть откроет сайт снова на том же телефоне — вход восстановится. Если сменил телефон — заходит заново по коду комнаты.

**На телефоне не грузится Python / долго «Загрузка Python».**
- Первый запуск ~10 с (скачивается Pyodide). Нужен нормальный интернет; на старых телефонах лучше Chrome/Safari последней версии.

**Тормозит при большом классе.**
- Рассчитано на ~30 человек. Для 60+ увеличьте `POLL_MS` в `app.js` (например, до 4000).

**Студент спорит, что код правильный.**
- Его код есть в `Submissions` (только успешные) и виден вам через «помогите»-ссылку в чате. Проверка уже прощает пробелы, регистр, `print` вместо `return`.

**Хочу пароль на создание комнат.**
- `TEACHER_PASSWORD` в начале скрипта → Сохранить → Новая версия.
